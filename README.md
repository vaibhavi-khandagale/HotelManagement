Hotel Management System

About the Project

The Hotel Management System is a Java web application used to manage hotel rooms, bookings, and customer operations.

Features

- Room management
- Room booking
- Customer registration
- Customer check-in and check-out
- Update and delete room records
- Database connectivity

Technologies Used

- Java
- Java Servlets
- HTML and CSS
- Apache Tomcat 9
- Eclipse IDE

Project Structure

- "src/main/java/com/hotel/" — Java source files
- "build/classes/" — Compiled Java classes

How to Run

1. Import the project into Eclipse.
2. Configure Apache Tomcat 9.
3. Configure the database connection in "DBConnection.java".
4. Set up the required database and tables.
5. Run the project on the Tomcat server.
